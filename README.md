# Agent Drawer

An [Omarchy](https://omarchy.org) plugin that runs your default coding agent in a
floating drawer under the menubar, with a panel for its size, usage, and toggle
shortcut.

The drawer is a real terminal window, so the agent session stays alive between
shows. Hiding parks it out of sight rather than killing it — you can slide back
in and pick up the same conversation.

## Features

- **Floats over everything.** The drawer slides in above all windows on
  whichever workspace you are on, in front of fullscreen apps.
- **Stays alive when hidden.** Hiding moves the window to an inactive special
  workspace instead of closing it, so long-running agent sessions survive.
- **Percentage sizing.** Width and height are percentages of the focused
  monitor, so the same setting looks right on any display.
- **Token usage.** Daily and weekly token counts, broken down by model, read
  from OpenCode's own local database.
- **Configurable shortcut.** Set the toggle combo in the panel; the binding is
  written to a clearly marked region of your Hyprland config so it survives
  reloads.

## Requirements

- Omarchy (Hyprland)
- `omarchy-agent` — the plugin launches your configured default agent
- `python3`, `jq`, `hyprctl`

## Install

Clone into your Omarchy plugins directory and restart the shell:

```sh
git clone https://github.com/solomonmay/agent-drawer \
  ~/.config/omarchy/plugins/agent-drawer
omarchy-restart-shell
```

Then add the bar widget:

```sh
omarchy bar put agent-drawer
```

The widget is live immediately — no shell restart is needed after that.

## Usage

| Action | Result |
| --- | --- |
| Left click the bar button | Open the settings and usage panel |
| Right click | Slide the drawer in or out |
| Middle click | Restart the drawer |

The drawer also has a command of its own. It lives in the plugin's `bin/`
directory, which is not on your `PATH`, so call it by full path — or add the
directory yourself:

```sh
export PATH="$HOME/.config/omarchy/plugins/agent-drawer/bin:$PATH"
```

```sh
agent-drawer show      # slide in
agent-drawer hide      # park it, agent keeps running
agent-drawer toggle    # whichever is opposite
agent-drawer restart   # relaunch the agent
agent-drawer status    # visible | hidden
```

## Settings

All settings live in the panel, under the bar button's left click.

| Setting | Default | Notes |
| --- | --- | --- |
| Usage refresh interval | `300`s | How often token counts are re-read |
| Drawer width | `44`% | Of the focused monitor |
| Drawer height | `50`% | Of the focused monitor |
| Toggle shortcut | `SUPER + SHIFT + A` | Empty switches it off |

Sizes are percentages rather than pixels so one setting works across displays
with different resolutions. Values are clamped to `10..100`.

`SUPER + SHIFT + A` collides with an existing Omarchy binding by default. The
plugin takes it over — that is the intent, but it means the shortcut stops
opening whatever used to own it.

## Environment variables

Settings changed through the panel are the normal way to configure this. The
environment variables below are useful for testing, or for scripting something
around the drawer.

| Variable | Purpose |
| --- | --- |
| `AGENT_DRAWER_WIDTH_PCT` | Width as a percentage, overriding the setting |
| `AGENT_DRAWER_HEIGHT_PCT` | Height as a percentage, overriding the setting |
| `AGENT_DRAWER_GAP` | Pixels between the drawer and the screen edges (default `8`) |
| `AGENT_DRAWER_OPEN_MS` | Slide-in duration (default `280`) |
| `AGENT_DRAWER_CLOSE_MS` | Slide-out duration (default `220`) |
| `AGENT_DRAWER_LAUNCH_TIMEOUT` | Seconds to wait for the agent to appear (default `8`) |
| `AGENT_DRAWER_OFFSCREEN_PAD` | How far off-screen the drawer parks (default `24`) |

## How the shortcut is stored

Omarchy has no first-class way for a plugin to declare a keybinding, so the
binding is written to a marked region at the end of
`~/.config/hypr/bindings.lua`:

```lua
-- agent-drawer-bind-start
-- Generated by the Agent Drawer panel. Edits inside this region are
-- replaced the next time the shortcut is changed.
hl.unbind("SUPER + SHIFT + A")
o.bind("SUPER + SHIFT + A", "Agent Drawer", "omarchy-shell -q agent-drawer drawerToggle")
-- agent-drawer-bind-end
```

Everything between the markers is regenerated whenever you change the shortcut,
so treat it as generated. Each change is applied with `hyprctl reload`, and the
previous combo is unbound first — Hyprland keeps bindings that a reload no
longer mentions, so without that the old shortcut would keep working.

Changing the shortcut takes over the new combo from whatever else owned it. If
something important stops working afterwards, that is usually why.

## How usage is read

Token counts come from OpenCode's own local SQLite database, so they cost
nothing extra and reflect real usage. The count includes cache reads, which
dominate a typical day's total.

## Troubleshooting

**The bar button is missing.** `omarchy bar put agent-drawer`.

**The drawer does not appear.** `agent-drawer status` reports `visible` or
`hidden`; if `hidden`, the window may still be launching — `agent-drawer
restart` and watch the journal.
**Nothing happens on the shortcut.** Check it is actually bound:

```sh
hyprctl binds -j | jq '.[] | select(.description == "Agent Drawer")'
```

**Plugin errors.**

```sh
journalctl --user --since '5 min ago' | grep -i agent-drawer
```
